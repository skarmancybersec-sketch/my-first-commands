### 1. `pkg update`
Phone er sob package er list ta update kore, jate notun kichu install kora jay.

### 2. `pkg upgrade`
Purono package gulo ke notun version e update kore dey.

### 3. `pkg install git`
Git install korar jonno use hoy, jeta diye GitHub e code upload kora jay.

### 4. `ls`
Folder er vitore ki ki file ache seta dekhar jonno. (List)

### 5. `pwd`
Ami ekhon kon folder e achi seta dekhay. (Present Working Directory)
